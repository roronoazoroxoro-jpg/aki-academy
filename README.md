# AKI-Academy

Aprendé a programar, idiomas y ciencia **gratis**, a la argentina.  
Un robot con gorra que dice AKI, toma mate y te banca la racha.

## Qué hay adentro

- **10 cursos de tecnología:** Python, JavaScript, HTML/CSS, React, TypeScript, SQL, Git, IA, robótica y ciberseguridad.
- **7 de ciencia:** matemáticas, física, química, biología, astronomía, economía e historia argentina.
- **25 idiomas** con bandera, audio y escritura real (incluye español argentino, quechua, hebreo, tailandés…).
- **Laboratorio** con Python real en el navegador (Pyodide), desafíos corregidos y webs en vivo.
- **Racha, vidas, medialunas, misiones, logros y liga** (del Potrero al Campeón del Mundo).

Colores: celeste, blanco y dorado. Progreso guardado en tu dispositivo (exportable).

## Cómo correrlo

```bash
npm install
npm run dev
```

Producción:

```bash
npm run build
npm run preview
```
